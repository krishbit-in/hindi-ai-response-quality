## Evaluation Criteria

I use the following criteria to review AI-generated responses:

- **Accuracy:** Is the information factually correct?
- **Relevance:** Does the response answer the user's question?
- **Clarity:** Is the language clear and easy to understand?
- **Hindi Quality:** Is the Hindi natural, grammatically correct and appropriate?
- **Helpfulness:** Does the response provide useful information?
- **Safety:** Is the response responsible and safe?
